## ✨ Features

- 🔬 **Genuine Image-Based Disease Detection**: Analyzes uploaded leaf photos with Google Gemini Vision AI.
- 📈 **Dynamic Sensor Telemetry**: Realistic historical trends correlated with crop pathology indicators.
- 🤖 **AgriBot AI Assistant**: Contextual farming advice powered by Gemini.
- 💧 **Smart Automated Irrigation**: Real-time threshold-based pump control.
- ☀️ **Clean Modern White Theme**: High-contrast, accessibility-focused light interface.
- 📱 **Dual UI Options**: Both a high-performance **Streamlit App** and a full **Node.js Web Dashboard**.

## 💻 Local Running Instructions

### Streamlit Application
```powershell
python -m streamlit run streamlit_app.py
```
Opens immediately at **http://localhost:8501**.

### Node.js Web Dashboard & AgriBot
```powershell
cd CropMonitor\backend
npm install
npm start
```
Opens immediately at **http://localhost:3000**.
